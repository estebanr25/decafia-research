PROJECT DESCRIPTION (replace "split agrupado sin fuga" section)
--------------------------------------------------------------------

This is a research project producing a journal article about the DECAFIA dataset — a multi-source, field-collected, annotated dataset for coffee leaf disease detection under Colombian Andean conditions.

Split: grouped by leaf ("split agrupado por hoja"). The split uses group-based assignment to prevent crop-parent and capture-series pairs from crossing split boundaries. It is NOT described as "leakage-free" or "sin fuga".

Official model: decafia_grouped_v1 (YOLOv8m, seed 42) on split_grouped_v1.

--------------------------------------------------------------------
MINADOR CAVEAT (†)
--------------------------------------------------------------------

Minador test images share group membership with training images through SIFT+geometric-verified transformed copies (the MINEIRO_99 component, 272 images). mAP@0.50 = 0.985 cannot be interpreted as performance on independent held-out leaves. Report it only with this caveat; do NOT report a CI.

Roya test images are NOT contaminated (the one candidate cross-component edge fails geometric verification). The roya CI issue is purely statistical (one group holds 53% of instances).
