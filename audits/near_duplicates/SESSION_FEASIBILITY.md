## 5. Recommendations

### 5.1 Why Session-Based Assignment Is Currently Impossible

Session-based data splitting requires temporal metadata (capture timestamps) to define which images belong to the same continuous capture sequence. Without timestamps, there is no way to know whether image A and image B were taken seconds apart (on the same plant, same lighting, same viewpoint) or months apart. All 2315 images in this dataset lack EXIF timestamps — either they were stripped during preprocessing, or the source images never had them (e.g., web-scraped images, format-converted images, or datasets shared without metadata).

### 5.2 Threshold Comparison

All five thresholds (5 min, 15 min, 30 min, 60 min, calendar day) yield the same result: zero sessions, zero assignable images, 2315 unplaceable images. There is no threshold that rescues session-based splitting for this dataset.

### 5.3 Recommended Threshold (If Future EXIF Recovery Is Possible)

If EXIF timestamps can be recovered (e.g., from original source files, sidecar files, or re-acquisition logs), we recommend **T = 15 minutes** as the primary threshold for the following reasons:

- **5 min**: Too aggressive — may split a single field walk into many micro-sessions if the photographer pauses.
- **15 min**: Reasonable for a field survey; matches typical rest/repositioning time between plots.
- **30 min**: Acceptable but risks merging two separate visits to different fields in the same morning.
- **60 min**: Likely to merge morning and afternoon sessions, defeating the temporal independence goal.
- **Calendar day**: Maximally lenient; merges all captures on the same day regardless of location shifts.

**Recommended threshold: 15 minutes** — best balance of temporal isolation and session granularity.

### 5.4 Immediate Action Items

1. **Recover EXIF from originals**: Check the original image files (pre-pipeline) for embedded EXIF.
2. **Check sidecar/log files**: Camera apps (e.g., drone GCS, field survey apps) often write separate timestamp logs.
3. **If irrecoverable**: Use filename-based ordering (if filenames encode capture order) or spatial clustering (GPS if available, or field plot IDs) as a proxy for session.
4. **Crop contamination**: The 405 crop-parent pairs are all cross-split — this is a data leakage risk. Address before final model evaluation regardless of session strategy.
